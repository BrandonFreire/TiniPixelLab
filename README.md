# Tini Pixel Art

## 📋 Descripción

Sistema de pedidos para un restaurante pequeño que permite gestionar y procesar pedidos de forma eficiente.

## 🎯 Características

- Gestión de pedidos
- Catálogo de productos/platos
- Cálculo automático de totales y actualización del carrito
- Interfaz amigable con el usuario

## 🛠️ Tecnologías Utilizadas

- **Frontend**: JavaScript, HTML, CSS
- **Backend**: Python
